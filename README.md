# anna-cottrill

## Work in progress features

1. As a logged-in user, I should see quest notifications on the startup screen.
  - How much time is left on the quest should be visible 
  - Each notification should be made to tell if it's expiring at a glance (ideally by changing background color)
2. As a logged-in user, I should able to create new quests and view all my quests. 
3. As a logged-in user, I should be able to add custom rewards in addition to current ones. 
4. As a logged-in user, I can click on a quest and see my progress.
5. While viewing a quest, I can mark quest tasks complete and gain exp. 
6. When I gain enough experience, I should be able to receive a random reward. 
7. An reward upon level up should unlock some new feature in the app like a custom theme or border. 
8. Upon completing a quest item, I should receive a random custom reward. 
  - if no custom reward is set, I should at minimum get more tiny sparks.
9. As a logged-in user, I should be able to create a new reward. 
  - This reward should be able to marked as repeatable. (If this reward should be reused)
  - It should have a name and a description. 
10. If a user logs in using another device, their data should be synchronized and kept up to date. 
11. As a logged-in user, I should be able to compare my progress to my friends and see their current quests.
